# ระบบขายหน้าร้าน (POS) + จัดการสต๊อกสินค้า

เว็บแอประบบขาย/สต๊อกสินค้า ใช้งานได้จากทุกที่ผ่านเบราว์เซอร์ สร้างด้วยสแตกยอดนิยม:
**Next.js 14 + Supabase (ฐานข้อมูล + ระบบล็อกอิน) + Vercel (โฮสติ้ง)**

## ฟีเจอร์
- ระบบผู้ใช้หลายคน พร้อมสิทธิ์ 2 ระดับ: **ผู้ดูแลระบบ (admin)** และ **พนักงานขาย (cashier)**
- บันทึกการขายแบบ POS (เลือกสินค้า คิดเงิน ตัดสต๊อกอัตโนมัติ) พร้อมใบเสร็จพิมพ์/ดูย้อนหลังได้
- จัดการสต๊อกสินค้า เพิ่ม/แก้ไข/ลบ แจ้งเตือนสต๊อกต่ำ
- นำเข้าสินค้าจากไฟล์ Excel (.xlsx/.xls/.csv) รองรับหัวคอลัมน์ภาษาไทยและอังกฤษ
- รายงานยอดขายรายวันและสินค้าขายดี (30 วันล่าสุด)
- ใช้งานได้ทุกที่ที่มีอินเทอร์เน็ต เปิดผ่านมือถือ/แท็บเล็ต/คอมพิวเตอร์

## โครงสร้างเทคโนโลยี
- Frontend/Backend: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- ฐานข้อมูล + ระบบล็อกอิน: Supabase (Postgres + Auth + Row Level Security)
- นำเข้า Excel: ไลบรารี `xlsx` (ประมวลผลในเบราว์เซอร์)
- โฮสติ้ง: Vercel (แนะนำ) — ฟรีสำหรับใช้งานเริ่มต้น

## ขั้นตอนติดตั้งและ deploy ขึ้นเว็บจริง

### 1. สร้างโปรเจกต์ Supabase (ฐานข้อมูล)
1. ไปที่ https://supabase.com สมัคร/ล็อกอิน แล้วกด **New Project**
2. ตั้งชื่อโปรเจกต์ ตั้งรหัสผ่านฐานข้อมูล เลือก Region ที่ใกล้ (เช่น Singapore)
3. เมื่อโปรเจกต์สร้างเสร็จ ไปที่เมนู **SQL Editor** แล้วนำโค้ดทั้งหมดในไฟล์ `schema.sql` (แนบมาด้วย) ไปรันครั้งเดียว
4. ไปที่ **Project Settings → API** คัดลอกค่า:
   - `Project URL` → ใช้เป็น `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → ใช้เป็น `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. ไปที่ **Authentication → Providers → Email** ปิดการยืนยันอีเมล (Confirm email) ถ้าต้องการให้สมัครแล้วใช้งานได้ทันที (แนะนำสำหรับใช้งานภายในร้าน)

### 2. ตั้งค่าโปรเจกต์
คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจาก Supabase:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxx
```

ทดสอบรันในเครื่อง:
```
npm install
npm run dev
```
เปิด http://localhost:3000

### 3. Deploy ขึ้น Vercel (ทำให้เข้าถึงได้จากทุกที่)
1. อัปโหลดโค้ดโฟลเดอร์นี้ขึ้น GitHub (สร้าง repo ใหม่แล้ว push โค้ดขึ้นไป)
2. ไปที่ https://vercel.com เชื่อมบัญชี GitHub แล้วกด **Add New Project** เลือก repo นี้
3. ในหน้า Environment Variables ใส่ `NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_ANON_KEY` ตามค่าจาก Supabase
4. กด **Deploy** รอสักครู่ Vercel จะให้โดเมนมาใช้งานได้ทันที เช่น `https://your-pos.vercel.app`
   (ภายหลังสามารถผูกโดเมนของตัวเองได้ในเมนู Domains)

> หมายเหตุ: หากต้องการให้ผมช่วย deploy ให้โดยตรงจาก Cowork สามารถกด "Connect" ที่ตัวเชื่อมต่อ Vercel และ Supabase ที่แนะนำในแชท แล้วแจ้งให้ดำเนินการต่อได้เลย

### 4. ตั้งผู้ดูแลระบบคนแรก
1. เปิดเว็บที่ deploy แล้ว สมัครสมาชิกบัญชีแรก (จะได้สิทธิ์ cashier โดยอัตโนมัติ)
2. ไปที่ Supabase → Table Editor → ตาราง `profiles` หา row ของบัญชีที่เพิ่งสมัคร แก้ค่า `role` เป็น `admin`
3. ล็อกอินใหม่ จะเห็นเมนู "จัดการสต๊อกสินค้า" และ "รายงาน" (เฉพาะ admin)

### 5. นำเข้าสินค้าจาก Excel
1. ไปที่เมนู **จัดการสต๊อกสินค้า** (ต้องเป็น admin)
2. กด **ดาวน์โหลดเทมเพลต Excel** เพื่อดูรูปแบบคอลัมน์ที่รองรับ
3. กรอกข้อมูลสินค้าในไฟล์ Excel ของคุณ แล้วกด **นำเข้าจาก Excel** เลือกไฟล์
4. ระบบจะเพิ่มสินค้าใหม่ หรืออัปเดต/บวกสต๊อกให้สินค้าที่มี SKU ซ้ำ

คอลัมน์ที่รองรับ (ไทย/อังกฤษ): รหัสสินค้า(sku), ชื่อสินค้า(name)*, หมวดหมู่(category), หน่วย(unit),
ราคาทุน(cost_price), ราคาขาย(sell_price)*, จำนวนคงเหลือ(stock_qty), จุดสั่งซื้อ(low_stock_threshold)
(* จำเป็นต้องมี)

## สิทธิ์การใช้งาน
| เมนู | ผู้ดูแลระบบ (admin) | พนักงานขาย (cashier) |
|---|---|---|
| แดชบอร์ด | ✅ | ✅ |
| บันทึกการขาย | ✅ | ✅ |
| ประวัติการขาย | ✅ (ทุกบิล) | ✅ (เฉพาะบิลตัวเอง) |
| จัดการสต๊อกสินค้า | ✅ | ❌ |
| รายงาน | ✅ | ❌ |

การกำหนดสิทธิ์บังคับใช้ที่ระดับฐานข้อมูล (Row Level Security) ไม่ใช่แค่ซ่อนเมนู จึงปลอดภัยแม้พยายามเข้าถึง URL ตรง ๆ
