# ระบบขายหน้าร้าน (POS) + จัดการสต๊อกสินค้า

เว็บแอประบบขาย/สต๊อกสินค้า ใช้งานได้จากทุกที่ผ่านเบราว์เซอร์ สร้างด้วยสแตกยอดนิยม:
**Next.js 14 + Supabase (ฐานข้อมูล + ระบบล็อกอิน) + Vercel (โฮสติ้ง)**

## ฟีเจอร์
- ระบบผู้ใช้หลายคน พร้อมสิทธิ์ 2 ระดับ: **ผู้ดูแลระบบ (admin)** และ **พนักงานขาย (cashier)**
- บันทึกการขายแบบ POS (เลือกสินค้า คิดเงิน ตัดสต๊อกอัตโนมัติ) พร้อมใบเสร็จพิมพ์/ดูย้อนหลังได้
- ส่วนลดได้ทั้งรายชิ้นและท้ายบิล, แบ่งชำระหลายช่องทางในบิลเดียว (เช่น เงินสด+โอน), รองรับขายเชื่อ
- ใบกำกับภาษีอย่างย่อ: ใส่เลขผู้เสียภาษี/ที่อยู่ลูกค้าได้ พร้อมข้อมูลร้าน (ตั้งค่าได้ในเมนู "ตั้งค่าร้าน")
- ระบบลูกค้า/สมาชิก: ค้นหา/เพิ่มลูกค้าที่หน้า POS สะสมแต้มอัตโนมัติ ตั้งวงเงินเชื่อและติดตามยอดค้างชำระได้
- ระบบซื้อสินค้าเข้า (Purchase Order) ผูกกับผู้จัดจำหน่าย: สร้างใบสั่งซื้อ รับสินค้าเข้าอัปเดตสต๊อก/ราคาทุนอัตโนมัติ
- รองรับเครื่องสแกนบาร์โค้ด (USB/บลูทูธ): ยิงรหัสสินค้าที่ช่องค้นหาในหน้า POS แล้วเพิ่มลงตะกร้าอัตโนมัติ
- แสดง/พิมพ์ใบเสร็จแบบเครื่องพิมพ์ความร้อน 80mm พร้อมสรุป VAT 7% (ราคาสินค้ารวม VAT อยู่แล้ว)
- ยกเลิก/คืนสินค้า (void) บิลที่บันทึกผิดพลาด โดยระบบจะคืนสต๊อกให้อัตโนมัติ และต้องยืนยันรหัสผ่านซ้ำก่อนยกเลิก (เฉพาะ admin)
- ระบบเปิด-ปิดกะเงินสด (cash shift): เปิดกะพร้อมเงินตั้งต้น ปิดกะแล้วกระทบยอดเงินสดที่คาดว่าจะมีกับที่นับได้จริง
- จัดการสต๊อกสินค้า เพิ่ม/แก้ไข/ลบ แจ้งเตือนสต๊อกต่ำ พร้อมหน้าปรับสต๊อกด้วยมือ (+/-) และประวัติการปรับ
- แจ้งเตือนสต๊อกต่ำอัตโนมัติทุกวันผ่าน webhook (ตั้งค่า URL ได้ในเมนู "ตั้งค่าร้าน" — รองรับ Slack/Discord/n8n/Make)
- นำเข้าสินค้าจากไฟล์ Excel (.xlsx/.xls/.csv) รองรับหัวคอลัมน์ภาษาไทยและอังกฤษ
- จัดการผู้ใช้ในระบบได้จากหน้าเว็บโดยตรง (เปลี่ยนสิทธิ์ admin/cashier) ไม่ต้องเข้า Supabase dashboard
- รายงานยอดขายรายวัน สินค้าขายดี และกำไรขั้นต้นโดยประมาณ เลือกช่วงวันที่เองได้ พร้อมปุ่มส่งออกเป็นไฟล์ Excel หลายชีต
- ประวัติการดำเนินการ (audit log): บันทึกการยกเลิกบิล ปรับสต๊อก เปลี่ยนสิทธิ์ผู้ใช้ รับชำระหนี้ และรับสินค้าเข้า
- ติดตั้งเป็นแอปบนมือถือ/คอมพิวเตอร์ได้ (PWA) พร้อมหน้าจอแจ้งเตือนเมื่อไม่มีอินเทอร์เน็ต
- ระบบรีเซ็ตรหัสผ่านผ่านอีเมล
- ใช้งานได้ทุกที่ที่มีอินเทอร์เน็ต เปิดผ่านมือถือ/แท็บเล็ต/คอมพิวเตอร์

## โครงสร้างเทคโนโลยี
- Frontend/Backend: Next.js 14 (App Router) + TypeScript + Tailwind CSS
- ฐานข้อมูล + ระบบล็อกอิน: Supabase (Postgres + Auth + Row Level Security)
- นำเข้า Excel: ไลบรารี `xlsx` (ประมวลผลในเบราว์เซอร์)
- โฮสติ้ง: Vercel (แนะนำ) — ฟรีสำหรับใช้งานเริ่มต้น

## ขั้นตอนติดตั้งและ deploy ขึ้นเว็บจริง

### 1. สร้างโปรเจกต์ Supabase (ฐานข้อมูล)
1. ไปที่ https://supabase.com สมัคร/ล็อกอิน แล้วกด **New Project**
2. ตั้งชื่อโปรเจกต์ ตั้งรหัสผ่านฐานข้อมูล เลือก Region ที่ใกล้ (เช่น Singapore)
3. เมื่อโปรเจกต์สร้างเสร็จ ไปที่เมนู **SQL Editor** แล้วนำโค้ดทั้งหมดในไฟล์ `schema.sql` (แนบมาด้วย) ไปรันครั้งเดียว
4. ไปที่ **Project Settings → API** คัดลอกค่า:
   - `Project URL` → ใช้เป็น `NEXT_PUBLIC_SUPABASE_URL`
   - `anon public key` → ใช้เป็น `NEXT_PUBLIC_SUPABASE_ANON_KEY`
5. ไปที่ **Authentication → Providers → Email** ปิดการยืนยันอีเมล (Confirm email) ถ้าต้องการให้สมัครแล้วใช้งานได้ทันที (แนะนำสำหรับใช้งานภายในร้าน)

### 2. ตั้งค่าโปรเจกต์
คัดลอก `.env.local.example` เป็น `.env.local` แล้วใส่ค่าจาก Supabase:
```
NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=xxxxxxxxxxxx
```

ทดสอบรันในเครื่อง:
```
npm install
npm run dev
```
เปิด http://localhost:3000

### 3. Deploy ขึ้น Vercel (ทำให้เข้าถึงได้จากทุกที่)
1. อัปโหลดโค้ดโฟลเดอร์นี้ขึ้น GitHub (สร้าง repo ใหม่แล้ว push โค้ดขึ้นไป)
2. ไปที่ https://vercel.com เชื่อมบัญชี GitHub แล้วกด **Add New Project** เลือก repo นี้
3. ในหน้า Environment Variables ใส่ `NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_ANON_KEY` ตามค่าจาก Supabase
4. กด **Deploy** รอสักครู่ Vercel จะให้โดเมนมาใช้งานได้ทันที เช่น `https://your-pos.vercel.app`
   (ภายหลังสามารถผูกโดเมนของตัวเองได้ในเมนู Domains)

> หมายเหตุ: หากต้องการให้ผมช่วย deploy ให้โดยตรงจาก Cowork สามารถกด "Connect" ที่ตัวเชื่อมต่อ Vercel และ Supabase ที่แนะนำในแชท แล้วแจ้งให้ดำเนินการต่อได้เลย

### 4. ตั้งผู้ดูแลระบบคนแรก
1. เปิดเว็บที่ deploy แล้ว สมัครสมาชิกบัญชีแรก (จะได้สิทธิ์ cashier โดยอัตโนมัติ)
2. ไปที่ Supabase → Table Editor → ตาราง `profiles` หา row ของบัญชีที่เพิ่งสมัคร แก้ค่า `role` เป็น `admin`
3. ล็อกอินใหม่ จะเห็นเมนู "จัดการสต๊อกสินค้า" และ "รายงาน" (เฉพาะ admin)

### 5. นำเข้าสินค้าจาก Excel
1. ไปที่เมนู **จัดการสต๊อกสินค้า** (ต้องเป็น admin)
2. กด **ดาวน์โหลดเทมเพลต Excel** เพื่อดูรูปแบบคอลัมน์ที่รองรับ
3. กรอกข้อมูลสินค้าในไฟล์ Excel ของคุณ แล้วกด **นำเข้าจาก Excel** เลือกไฟล์
4. ระบบจะเพิ่มสินค้าใหม่ หรืออัปเดต/บวกสต๊อกให้สินค้าที่มี SKU ซ้ำ

คอลัมน์ที่รองรับ (ไทย/อังกฤษ): รหัสสินค้า(sku), ชื่อสินค้า(name)*, หมวดหมู่(category), หน่วย(unit),
ราคาทุน(cost_price), ราคาขาย(sell_price)*, จำนวนคงเหลือ(stock_qty), จุดสั่งซื้อ(low_stock_threshold)
(* จำเป็นต้องมี)

## สิทธิ์การใช้งาน
| เมนู | ผู้ดูแลระบบ (admin) | พนักงานขาย (cashier) |
|---|---|---|
| แดชบอร์ด | ✅ | ✅ |
| บันทึกการขาย (POS) | ✅ | ✅ |
| เปิด-ปิดกะเงินสด | ✅ | ✅ (เฉพาะกะตัวเอง) |
| ประวัติการขาย | ✅ (ทุกบิล + ยกเลิกบิลได้) | ✅ (เฉพาะบิลตัวเอง) |
| ลูกค้า/สมาชิก | ✅ (แก้วงเงินเชื่อได้) | ✅ (เพิ่ม/ค้นหา/รับชำระหนี้) |
| จัดการสต๊อกสินค้า | ✅ | ❌ |
| ปรับสต๊อกด้วยมือ | ✅ | ❌ |
| ใบสั่งซื้อ + ผู้จัดจำหน่าย | ✅ | ❌ |
| รายงาน + ส่งออก Excel | ✅ | ❌ |
| จัดการผู้ใช้ | ✅ | ❌ |
| ประวัติการดำเนินการ | ✅ | ❌ |
| ตั้งค่าร้าน | ✅ | ❌ |

การกำหนดสิทธิ์บังคับใช้ที่ระดับฐานข้อมูล (Row Level Security + SECURITY DEFINER RPC) ไม่ใช่แค่ซ่อนเมนู จึงปลอดภัยแม้พยายามเข้าถึง URL ตรง ๆ

## ข้อจำกัดที่ควรทราบ
- ระบบยังไม่รองรับหลายสาขา/หลายร้านในบัญชีเดียว (multi-tenant) — เหมาะกับร้านเดียวหรือใช้แยกโปรเจกต์ต่อสาขา
- อีเมลรีเซ็ตรหัสผ่านจะส่งได้เฉพาะอีเมลที่ยืนยันกับผู้ให้บริการ SMTP จนกว่าจะตั้งค่าโดเมนของตัวเอง
- เครื่องพิมพ์ใบเสร็จรองรับผ่านฟังก์ชันพิมพ์ของเบราว์เซอร์ (ปรับ CSS ให้พอดีกระดาษ 80mm) ยังไม่ใช่การเชื่อมต่อไดรเวอร์เครื่องพิมพ์โดยตรง
- เครื่องสแกนบาร์โค้ดต้องเป็นรุ่นที่ทำงานแบบคีย์บอร์ด (USB-HID/บลูทูธคีย์บอร์ดโหมด) และตั้งรหัสสินค้าให้ตรงกับ SKU ในระบบ
- แจ้งเตือนสต๊อกต่ำส่งเป็น JSON ไปยัง webhook ทั่วไป (เข้ากับ Slack/Discord/n8n/Make) ไม่ได้เชื่อมต่อ LINE Notify โดยตรง — หากต้องการแจ้งเตือนเข้า LINE แนะนำตั้ง n8n/Make เป็นตัวกลางรับ webhook นี้แล้วส่งต่อเข้า LINE
- PWA แคชเฉพาะไฟล์หน้าตาแอป (JS/CSS/ไอคอน) เพื่อให้เปิดแอปได้เร็วขึ้นและติดตั้งเป็นแอปได้ ไม่ได้รองรับการขายแบบ "ออฟไลน์เต็มรูปแบบ" — หากไม่มีอินเทอร์เน็ตจะไม่สามารถบันทึกการขายหรือดูข้อมูลสต๊อกได้ เนื่องจากข้อมูลทั้งหมดต้องซิงก์กับฐานข้อมูลกลางแบบเรียลไทม์เพื่อความถูกต้องของสต๊อกและยอดขาย
- แต้มสะสมคำนวณแบบคงที่ (1 แต้มต่อ 100 บาท) ยังปรับอัตราหรือตั้งโปรโมชันแต้มพิเศษผ่านหน้าเว็บไม่ได้ (ต้องแก้ที่ฟังก์ชัน `create_sale` ในฐานข้อมูล)
